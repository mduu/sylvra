# Sylvra — App Logo Prompt (ChatGPT image generation)

## Main prompt

```
Design a premium macOS app icon for "Sylvra", a native Mac app for calm, focused code review.
The name comes from Latin "silva" (forest). Mood: a quiet place for focused work — modern, elegant, refined.

Shape & format: macOS app icon, 1024x1024, rounded-square (squircle) shape in the current macOS style,
centered, subtle depth, soft realistic lighting from the top, gentle drop shadow. Liquid-glass feel:
layered translucent glass with soft refraction and a fine specular edge highlight.

Motif: a single abstract, minimalist leaf whose central vein is formed by two parallel lines that split
and rejoin — subtly evoking a code diff / branch and merge. One side of the leaf is slightly brighter
than the other, hinting at "before / after". Geometric, precise, no clutter.

Colors: deep forest green to dark emerald background gradient, the leaf in frosted glass with a soft
sage-to-mint glow, a very fine warm brass/champagne-gold accent line on the vein. Restrained palette, high contrast, luxurious but calm.

Style: minimal, sophisticated, Apple design language, crisp vector-like edges, no text, no letters,
no code symbols like brackets, no cartoon style, no busy texture. Must remain recognizable at 16x16.
```

## Variations

1. **Monogram** — replace the leaf with an elegant, geometric letter "S" shaped like a flowing stream or a leaf stem, split into two parallel strokes (diff lines) that converge at the ends. Same colors and glass material.
2. **Clearing** — a top-down view of a circular forest clearing: concentric rings of stylized tree canopies in deep greens, with a calm bright glass circle in the center (the focus). A thin gold line crosses the clearing like a highlighted code line.
3. **Canopy lines** — three to four horizontal, softly rounded bars like lines of code, staggered in length, whose right ends curve upward into leaf tips; one bar glows with a subtle green-teal-violet gradient (the "AI highlight").

## Follow-up prompts

- "Make it simpler and more iconic; remove one element."
- "Create a dark-mode and a tinted (monochrome) variant for macOS."
- "Show it at 1024, 128, 32 and 16 px side by side to check legibility."
- "Generate the same icon as separate layers (background, glass leaf, accent line) on transparent backgrounds for Apple Icon Composer."
